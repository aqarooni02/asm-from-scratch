# Useful links

| Link | What it is |
|------|------------|
| [Bash cheatsheet (devhints.io)](https://devhints.io/bash) | Concise quick-reference for Bash scripting — variables, loops, functions, conditionals, arrays. Handy for the shell commands around your asm builds. |
| [Makefile Tutorial by Example](https://makefiletutorial.com/) | Hands-on, example-driven guide to GNU Make — rules, variables, automatic variables, pattern rules, plus a cookbook template for medium-sized projects. |
| [NASM Tutorial (LMU, Ray Toal)](https://cs.lmu.edu/~ray/notes/nasmtutorial/) | x86-64 NASM tutorial covering standalone syscall programs through C interop, calling conventions, and examples like `fib` and `maxofthree` — closely matches this repo. |
| [Intel SDM — instruction reference](https://intel.github.io/SDM/sdm.html) | Official Intel 64 / IA-32 instruction reference (Volume 2 preview site) — authoritative per-instruction docs, plus links to the full SDM, intrinsics guide, and optimization manual. |
